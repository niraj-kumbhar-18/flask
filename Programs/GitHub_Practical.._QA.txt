22. Generate a Python program using GitHub Copilot to sort a list of numbers in ascending
order.
Answer:
 1.   open Visual Studio Code
 2.   install GitHub Copilot extension from Extensions and sign in with GitHub
 3.   create new file sort_numbers.py
 4.   write comment : # Write a Python program to sort a list of numbers in ascending order
 5.   press Enter, Copilot suggests the code, press Tab to accept
 6.   save the file (Ctrl+S)
 7.   open terminal
 8.   python sort_numbers.py

27. Create an Issue titled "Create Student Management Module" and assign the
enhancement label to it. Close the created Issue after marking it as completed.
Answer:

 2.   click Issues tab
 3.   click New issue
 4.   title : Create Student Management Module
 5.   write a description
 6.   on the right side click Labels, select enhancement
 7.   click Submit new issue
 8.   open the created issue, click Close issue (Close as completed)
 9.   go to Issues tab, click Closed, check the issue is closed
